# akjilbot — 악질봇 4.0.0

카카오톡 MessengerBotR API2에서 동작하는 카드 전투·탐험 봇입니다. 실행 원본, 카드·직업 설계, 규칙 문서와 자동 검사를 함께 보관합니다.

## 파일 구조

- `악질봇4.0.0.js`: 휴대폰 봇에 등록할 단일 배포 파일. 자동 생성됩니다.
- `akjilbot4/src/`: 실제 게임·AI·저장·UI 코드.
- `akjilbot4/content/`: 직업·상대·카드 설계 자료.
- `akjilbot4/docs/`: 규칙과 최근 변경 사항.
- `akjilbot4/tests/`: 전투·저장 복구·관리자·UI·AI 검사.
- `AGENTS.md`: 코딩 에이전트용 편집·검증 안내.

## 개발

Node.js 24를 사용합니다. 외부 npm 의존성 설치는 필요하지 않습니다.

```sh
npm run build
npm run check
npm test
```

`npm test`는 26종 상대의 자동 전투와 저장·재접속 검사도 포함하므로 수 분이 걸릴 수 있습니다. Android 실제 기기에서의 실행 속도·알림·파일 API 검증은 별도로 필요합니다.

원본을 수정한 뒤 반드시 다시 빌드합니다. 휴대폰에는 루트의 `악질봇4.0.0.js`만 등록합니다. 기존 유저 저장 폴더는 코드 파일과 별개이며 이 저장소에 포함하지 않습니다.

## 현재 구현과 설계 확인

플레이 가능 직업은 거프·사일런트·셀레스테·데칼·아감마간·노틸러스 6종입니다. 노틸러스는 타격 3·투하 2·파묻힌 보물 3·서프라이드 2장으로 시작합니다.

- [플레이어 직업](akjilbot4/docs/플레이어-직업.md)
- [전투 후 보상·선술집·중립 카드와 보물](akjilbot4/docs/전투후-선술집-개편.md)
- [룬 카드군](akjilbot4/docs/룬-카드군.md)
- [상대별 덱](akjilbot4/docs/상대별-덱.md)
- [엔진 확장 규약](akjilbot4/ENGINE-CONTRACT.md)

중립 카드 풀 111종, 중립 보물 풀 62종을 사용합니다. 전투 후 직업 카드 묶음 → 휴식·제련 → 이벤트 → 선술집으로 진행합니다. 이벤트는 아직 내용 없이 단계만 준비되어 있습니다.

계정 재화는 코인(C), 탐험과 선술집 재화는 골드입니다. 위력·혈석·단검·해오름·어스름과 룬 카드군의 기반 기능이 있습니다. 실제 룬 카드 목록은 아직 추가되지 않았습니다.

오래된 원고와 변경 기록에는 이전 규칙이 남아 있을 수 있습니다. 실행 결과는 `src/`와 빌드된 파일을 확인하고, 콘텐츠 변경은 최신 직업 설계 및 위 문서를 함께 확인하세요.
