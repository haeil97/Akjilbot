# Project instructions

This repository contains a Korean KakaoTalk card-battle bot. Communicate with the user in Korean unless requested otherwise.

## Layout and build

- Edit `akjilbot4/src/`, `akjilbot4/content/`, and relevant docs/tests.
- The root `악질봇4.0.0.js` is generated by `node akjilbot4/build.js`; regenerate it after runtime/content changes.
- Use Node.js 24. There are no external npm dependencies.
- `npm run build` builds and validates the catalog; `npm run check` checks bundle syntax; `npm test` runs the full test suite, including slow playthrough tests.
- Android production modules must remain compatible with the existing ES5-style JavaScript and Java APIs. Node-only code belongs in development scripts/tests.

## Game conventions

- Preserve save compatibility. All battle state and queued choices must be JSON serializable.
- Do not reset user progress, delete save files, or weaken durable saving or duplicate-command protection.
- Keep account coins (`user.gold`, displayed as C) separate from run/tavern gold (`run.gold`). These legacy field names are intentional.
- AI may use public information and sampled unknown hands; never expose the actual hidden opponent hand or deck order. Keep the 5-second planning budget and fallback behavior.
- The current class document is `akjilbot4/docs/플레이어-직업.md`.
- Current post-battle flow is documented in `akjilbot4/docs/전투후-선술집-개편.md`. Rune behavior is in `akjilbot4/docs/룬-카드군.md`.
- Do not invent unfinished card, treasure, or event effects. Agamaggan has a completed ten-card starting deck and is selectable. Nautilus remains locked until its starting deck is provided. No actual rune cards have been specified yet.
- Historical manuscripts may describe old behavior. Prefer current source code and the latest relevant design document, following the user's requested changes.
