# Battle v3 extension contract

All state is JSON. `A4.Battle` wraps legacy `A4.Combat` for `catalog.config.engineVersion===3` or battle.rulesVersion 3.

Extension modules `A4.CardRules`, `A4.TreasureRules`, `A4.BossRules` expose `run(ctx, task)` (return true if handled), `hook(ctx, event)` and optionally `modify(ctx, what, data)` (mutate data synchronously; no choices). A card has `rule: 'id'`, normal effects remain supported. Core dispatches `{kind:'card',module:'cards'|'treasures'|'boss',side:'player'|'enemy',card,def,critical,free,step:0}`. Power tasks have kind power and module boss, side, power. Custom continuations must specify module and op; same run handler handles them. Event hooks see `event.type`.

Context: `ctx.battle`, `ctx.catalog`, `ctx.rng`, `ctx.task`, `ctx.side` (task side or event side), `ctx.self`, `ctx.foe`; `ctx.other(side)`, `ctx.fighter(side)`, `ctx.def(card)`, `ctx.cost(side,card)`, `ctx.copy(value)`, `ctx.pick(list)`, `ctx.sample(list,n)`, `ctx.log(text)`.

Mutation methods: `ctx.draw(side,n,filter?,options?)` returns successfully drawn instances; filter function sees card def and instance. It refills from rest and honors overflow/cast-on-draw. `ctx.damage(sourceSide,targetSide,n,options?)`, `ctx.heal(side,n,options?)`, `ctx.shield(side,n)`, `ctx.mana(side,n,recover?)`, `ctx.overload(side,n)`. Damage options `{card, ignoreArmor, unblockable, noBonus}`; default card source is current task card. Healing applies current card bonus. `ctx.generate(side,cardId,{upgraded,zone, ...instanceOverrides}?)` returns instance. `ctx.move(side,uid,zone,options?)` moves among own zones and returns card, `ctx.add(side,card,zone?)` adds detached card with overflow rule. `ctx.remove(side,uid)` detaches returns card; `ctx.find(side,uid)` searches zones. `ctx.shuffle(array)` mutates. `ctx.upgrade(card)` skips treasures/exclusive/already upgraded. `ctx.limit(side)` returns dynamic hand cap.

Queue: `ctx.enqueue(task)` appends; `ctx.prepend(taskOrArray)` prepends in given order. `ctx.cast(side,card,{free:true,copy:true}?)` queues automatic card effect without mana/use-count/counter. `ctx.emit(type,data)` enqueues event. `ctx.schedule(turn,phase,task)` stores serialized task; phase STANDBY or END or MAIN2.

Choice: `ctx.discover(side,options,continuation,{label,sourceZone}?)` samples at most 3 distinct names and pauses for player or autochooses for enemy. Returned choice is delivered as `task.choice` (full option clone), `task.options` original offered options. Continue via module run using `step` or `op`. **Handler must return after requesting choice.** Generic choice with >3 desired options: `ctx.choose(side,options,continuation,{label}?)`, no sampling. For 3 repeated discoveries chain continuation. Player choice state is battle.pendingChoice with options,label,continuation; always persisted. Options may be card instances or `{id,name,text}`. `ctx.runChange(change)` appends battle.runChanges (parent integrates types addCard/removeCard/addTreasure/removeTreasure/setHeroPower).

Events: battleStart (after opening hand), standby (after mana refresh + basic draw), beforeMain (phase), end (before temporary discard), afterEnd; cardUsed `{side,card,def,free,countered,critical}`; cardRest `{side,card}`; draw `{side,card,overflow}`; damage `{side:target,sourceSide,amount,hpDamage,card}`; heal `{side,amount,requested}`; overload `{side,amount}`; powerUsed `{side,power}`; counter `{side,card,targets:[instances]}`; discovered `{side,choice,options,sourceZone}`; beforeDeath (phase effects finished).

Modifiers: handLimit `{side,value}`; cardCost `{side,card,def,value,first}`; powerCost `{side,power,value}`; damage `{sourceSide,side:target,card,value,unblockable,ignoreArmor}`; heal `{side,card,value}`; beforeCounter `{entries:{player:[entry],enemy:[entry]}}`; basicDraw `{side,replace:false}`. Entries card,def,countered,didCounter,targets. basicDraw modifier may enqueue custom choice and set replace true.

State conventions: fighters contain status plain object, hand/deck/rest/excluded/inFlight, passives (each `{type,...}`), treasureIds, heroPower, heroPowerUsedTurn, playedThisTurn, usedThisTurn array entries, lastTurnCards, damageTakenThisTurn, overloadNext/overloadLocked, manaGrowth; instance overrides cost, costDelta, temporaryUntil, excludeOnUse, originalCardId, transformed, noUpgrade. Arbitrary module namespaces under fighter.status allowed. core card locks status.cardLocks array `{from,until,elements?}` (listed elements are forbidden). battle.turn starts 0 and battle.phase MAIN1/MAIN2; queue processing phase END/STANDBY can pause. `battle.resolution={queue,entries,phase}` present while processing. `battle.outcome` ongoing/victory/defeat. `battle.specialDefeat` / `battle.specialVictory` booleans consumed at phase-death. `battle.restartRequested` restarts saved encounter specs after consuming rescue. Game must synchronize restartSpecs after permanent run changes. A final guard at 2000 jobs rejects unexpected pathological chains; known reflection/draw-cast lethal chains stop reacting while independent submitted effects continue.

Integration additions: damage -> damageTaken modifiers separate additive bonuses and prevention; heal -> healFinal separates bonuses from reduction/redirection. beforeCounter -> afterCounter supports final immunity/forest rules. Entries can set reflectedBy to redirect effects while leaving the physical card with its original owner. cardResolved fires after a successful card's effects; cardUsed includes ordinal and paidCost. damage events include reactionDepth and reactiveAllowed; one reflection from an initially lethal direct hit is allowed, further lethal reaction chains stop. Initial four cards are dealt without draw events; turn 0 does run standby event hooks (no extra basic draw). Generic choose is not discovery; discover emits discovered before its continuation, avoiding delayed mirror bonuses in repeated discoveries. Event card snapshots reconnect to the live instance by UID when available. ctx.draw supports arbitrary instance override options; generated/copied cards never inherit runUid/runCardUid/treasureSlot.
