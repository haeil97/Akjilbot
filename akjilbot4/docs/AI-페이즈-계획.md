# 두 메인 페이즈의 AI 계획

메인 1에서 모두 쓰기, 쉬기, 일부 카드만 쓰기, 영웅 능력 보류를 후보로 비교합니다. 메인 1 실제 규칙을 가상 실행하고, 남은 카드·마나·영웅 능력으로 메인 2 후속 행동을 최대 두 개 비교합니다. 전투 중 얻은 마나와 드로우, 능력의 턴당 사용 제한, 지속 효과·카운터·종료 효과를 실제 엔진으로 처리합니다. 메인 2에 도달하면 새 공개정보로 다시 계획하므로 첫 계획을 고정 실행하지 않습니다.

메인 1에 카드를 사용한 뒤 메인 2에서 실제로 쓸 수 있는 카드나 영웅 능력을 남기는 행동에는 작은 대응 여유 점수를 줍니다. 사용 불가능하거나 남은 마나로 낼 수 없는 카드를 보유하는 것만으로는 점수를 주지 않습니다. 드로우는 손패에 추가 선택지가 필요하고 뽑을 자원·손패 공간·후속 행동용 마나가 있을 때 메인 1 사용에 작은 우선순위를 줍니다. 다음 턴 사용 제한이 있는 완전 빙결이나 지연해서 받는 황금궤 등은 즉시 드로우 이득으로 보지 않습니다. 드로우 우선 후보를 현재 탐색 후보에 별도로 포함하며, 즉시 처치는 페이즈 2까지 미루는 처치보다 우선합니다. 이 점수는 강제 분할 규칙이 아니며, 전투 결과·생존·효과 연계의 이득이 크면 한 페이즈에 모두 사용합니다.

분할 선호는 상대가 지금 카드를 낼 명확한 증거가 없어도 적용합니다. 결과가 비슷하면 메인 1에서 한 장만 내고 대부분을 메인 2에 몰기보다, 두 페이즈의 사용 장수가 어느 정도 균형을 이루는 후보를 선호합니다. 남은 마나로 사용할 수 있는 카드 수를 기준으로 하므로 무조건 손패 절반을 내는 규칙은 아닙니다. 드로우 및 균형 분할 후보를 유지하고, 쉬기 후보를 추가할 때 이 후보를 제거하지 않습니다. 실제 시뮬레이션 후보 수와 실행 횟수 상한은 유지합니다.

플레이어의 공개된 카드 사용 및 쉬기 기록을 메인 1과 메인 2로 분리하여 속성·제출 장수·쉬기 빈도를 추정합니다. 최근 기록에 더 무게를 주며, 다른 페이즈 기록은 약한 참고로 사용합니다. 전투 밖으로 유지하는 기록은 최근 48개 페이즈의 카드 ID·속성·강화 여부·카운터 여부만 포함하고 손패·덱·발견 선택은 저장하지 않습니다. 기록이 적으면 여러 추정 상황을 비교합니다. 공개된 제한·변경된 속성과 현재 손패 장수·마나를 우선 적용합니다.

최대 4개 현재 후보와 2개 추정 상황을 비교하며, 실제 페이즈 실행은 최대 24회, 실행당 큐 처리는 최대 360회입니다. 단일 행동은 실행을 생략하고 명확한 판단은 일찍 종료합니다. 실제 상태와 RNG를 변경하지 않습니다. 모든 가능한 분할·무작위 결과를 탐색하는 최적해 보장은 하지 않습니다. 승리 확정·생존·효과 연계가 더 좋으면 한 페이즈에 모두 사용하는 선택도 가능합니다.

계산량 최적화: 마나가 부족한 조합은 효과 평가 전에 가지를 잘라냅니다. 합법적인 카드 조합이 96개 이하이면 모두 평가합니다. 그보다 많으면 개별 카드 점수로 추린 상위 64개와 모든 단독·2장 조합, 마나 생성·과열·금단의 불꽃·유령 강탈자가 포함된 3장 조합, 장수 및 속성별 대표 후보를 평가합니다. 영웅 능력 포함 여부와 주요 순서 대안도 비교합니다. 큰 행동 공간에서는 전체 조합 탐색과 다른 판단이 나올 수 있습니다.

동일한 후보의 마나 지출이 같으면 영웅 능력 포함 여부를 바꿀 때 카드 묶음 평가를 재사용합니다. 카드 정의 캐시는 한 번의 계획 안에서만 유지하고 카드 상태가 변경되면 별도 항목을 사용합니다. 제출 이후 남은 손패의 신의 권능 오라 수치는 묶음마다 한 번만 계산합니다. 전투 시뮬레이션 수, 성향 예측, 페이즈 2 후속 탐색은 줄이지 않습니다.

실행 로그는 대기·처리·저장·전송 시간을 나눠 기록합니다. 저장은 스냅샷 인코딩·체크섬·두 사본의 내구성 쓰기 및 반환 복사까지 포함하며, 게임 계산·검증·저장 전 복사는 처리 시간에 포함됩니다. 1초 이상 걸린 AI 계획과 타이머 처리도 따로 기록합니다. 시간 측정은 계산 결과나 저장된 RNG에 영향을 주지 않으며, 앱이 메시지 콜백을 호출하기 전에 지연시킨 시간은 대기 측정에 포함되지 않습니다.

손패 한도보다 3장 이상 여유가 있으면 한 페이즈에 비용이 0인 카드를 대량으로 쓰는 행동에 보존 비용을 반영합니다. 특히 같은 속성의 0코스트 카드를 동시에 난사하는 행동보다 일부를 다음 턴으로 넘기는 행동을 선호합니다. 실제 마나를 지불하는 카드는 이 보존 비용에서 제외합니다. 메인 2에서 유효한 유료 카드를 써서 남은 마나를 활용하는 선택에는 작은 우선순위를 줍니다. 일시적인 카드와 신의 권능: 징벌의 레스트 연계, 즉시 처치 결과는 별도로 평가하며 손패 압박이 높으면 이 보존 비용을 적용하지 않습니다.

전투 시작 시 플레이어의 실제 탐험 덱을 공개된 구성으로 기록합니다. 카드별 장수·강화 여부·고정 비용 변경과 카드형 보물이 포함되며, 지속형 보물 보유도 공개 정보로 사용합니다. 이 기록에는 UID와 현재 영역·섞인 순서가 없습니다. AI는 기록된 구성을 바탕으로 손패와 덱을 추정하며 실제 숨겨진 영역을 읽지 않습니다. 신규 전투에서만 시작 덱을 다시 기록하고, 이전 저장 전투에 기록이 없으면 기존 추정 방식을 사용합니다.

사용형 영웅 능력은 카드 장수를 소모하지 않는 이점을 소폭 추가로 평가합니다. 이 추가 점수는 이전보다 줄여 매 턴 영능만 사용하는 선택으로 과하게 치우치지 않게 합니다. 효과가 유효하고 보존할 손패가 있을 때 적용하며, 첫 3턴에는 이후보다 높은 가치를 줍니다. 손패 압박이 크거나 영능과 함께 손패를 모두 소모하면 이점이 줄어듭니다. 빈 대상·완전한 체력 등으로 효과가 없는 영능에는 추가 점수를 주지 않고, 즉시 처치·생존과 사용 가능 조건을 우선합니다. 피카츄는 공개된 시작 덱의 전기 비율과 공개 속성 변경으로 상대 손패의 전기 카드 수를 추정합니다.

최종 후보 중 최고 점수에서 1.5점 이내이고 각 가상 상황의 승패 결과가 최고 후보와 같은 행동을 최대 3개 남깁니다. 제출 카드 집합과 영능 사용 여부가 같고 순서만 다른 후보는 한 행동으로 합쳐 확률을 중복 배정하지 않습니다. 3개이면 1위 60%·2위 25%·3위 15%, 2개이면 60:25 비율(약 70.6%·29.4%), 하나이면 100%로 선택합니다. 최고 판단과 명확한 점수 차이나 다른 승패 결과가 있으면 무작위 선택 대상으로 넣지 않습니다. 선택 난수는 공개 전투 상태의 해시로 만든 별도 난수이며 실제 카드 효과의 RNG를 사용하지 않습니다. 같은 상태에서 재개·재계산해도 선택이 바뀌지 않고, 상태가 바뀌면 새로운 선택이 가능합니다.
