# 하수인과 대상 지정

하수인 기능만 구현했으며 현재 실제 상대에게 배치한 하수인은 없다. 실제 이름·체력·스킬·소환 조건은 후속 명세로 등록한다. `content/하수인-설계.json`의 `minions`, `skills`가 등록 원본이다. 기존 탐험과 기존 저장 데이터는 하수인 없이 계속 동작한다.

## 하수인 정의

- `minions`의 각 항목은 `id`, `name`, `maxHp`, `skills`, `selection`을 갖는다. `skills`는 스킬 ID 목록, `selection`은 `cycle`(순서대로 순환) 또는 `random`(매번 무작위)이다.
- `skills`의 각 항목은 `id`, `name`, `text`, `effects`를 갖는다. `effects`는 기존 효과 형식이다. `target: "self"`의 회복·방어도는 하수인 자신에게, 일반 드로우·마나 등 자원 효과는 소유한 본체에게 적용한다. 기존 카드 규칙을 스킬로 재사용할 때는 `cardRule`에 규칙명을 지정할 수도 있다. 스킬은 카드 사용·마나 지불·카운터 판정을 일으키지 않는다.
- 상대의 전투 명세 또는 `catalog.enemies[상대ID].startingMinions`에 하수인 ID 목록을 지정하면 그 하수인과 시작한다. 영웅 능력 등에서 `{type: "summonMinion", minionId: "등록ID"}` 효과를 사용하면 소환한다.
- 소환 시 준비할 스킬을 확정한다. 소환된 턴의 엔드 페이즈부터 한 번 행동하며, 행동 뒤 다음 스킬을 준비한다. 무작위 선택 결과·순서·이미 행동한 턴은 저장된다. 같은 엔드 이벤트가 다시 처리되어도 중복 행동하지 않는다.
- 체력 0인 하수인은 행동·대상 목록에서 빠진다. 하수인이 모두 죽어도 본체가 살아 있으면 전투는 계속된다. 본체가 죽으면 기존 승패 규칙을 따른다.

## 표시와 입력

본체의 `■` 상태 아래에 살아 있는 하수인을 `□ 이름: ❤️ 현재/최대`로 표시하고, `》'스킬명'을 준비한다.`와 하수인의 상태 이상을 표시한다. 준비한 스킬은 공개 정보이며 상대의 손패나 카드 계획은 공개하지 않는다. `+도감 스킬명`은 `[🌕] 스킬명 | 스킬`과 효과 설명을 표시한다.

대상은 본체가 1, 살아 있는 첫 하수인이 2, 다음 하수인이 3이다. 카드가 해석될 때는 입력 당시 하수인 고유 ID를 사용하므로 다른 하수인이 먼저 죽어도 지정 대상이 바뀌지 않는다.

- `11`: 손패 1번을 본체에 사용한다.
- `12`: 손패 1번을 첫 하수인에게 사용한다.
- `22 33`: 손패 2번을 첫 하수인에게, 3번을 두 번째 하수인에게 사용한다.
- `1`: 대상을 생략하면 본체에 사용한다.
- 큰 번호는 `카드번호:대상번호`로 구분할 수 있다. 예: `11:1`, `2:10`.

`적`으로 표시된 지정 효과만 하수인을 선택할 수 있다. `상대`, `내`, `나`, `자신`은 본체를 뜻한다. 예를 들어 소각의 피해는 지정한 하수인에게 줄 수 있지만, 사용 카드 제외는 상대 본체의 카드 영역에 적용한다. `모든 적`, `무작위 적`은 살아 있는 본체와 하수인을 포함한다. 다단 공격의 대상이 죽으면 남은 공격을 본체에 돌리지 않는다.

## 2026-11 카드 목록 교체

- 거프 직업 보상 풀: `content/거프-개편.json`의 40종. 시작 덱은 유지한다. 목록에서 빠진 옛 카드는 신규 획득 풀에서 제외하되, 기존 저장 덱을 읽을 정의는 보존한다.
- 중립 카드 풀: `content/중립-개편.json`의 105종. 자연의 해독·신의 권능: 재생은 봇 전용 정의로 유지한다. 룬 이름이 들어간 폭발의 룬은 💎 룬 카드가 아니다.
- 중립 보물 풀: 같은 파일의 63종. 응급 치료 키트를 포함한 거프 전용 보물 6종은 별도 직업 풀에 등록한다. VIP 회원권은 물품별로 10~30% 할인율을 한 번 뽑아 저장한다. 골드 가격은 내림하며 최소 1이다.
- 취약은 기본 50% 증가다. 불의 심장이 활성화되면 취약 피해 증가가 총 75%가 된다. 바리케이드+는 비용 2이며 활성 룬인 동안만 방어도가 유지된다.
- `옭아메기+`와 `동력 전환+`로 섞여 온 강화형 제목은 각각 같은 카드의 강화형인 `옭아매기+`, `이건 내 거야!+`로 통일했다.
