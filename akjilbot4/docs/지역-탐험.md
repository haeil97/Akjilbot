# 4지역 탐험

새 탐험은 아래 지역을 순서대로 진행한다. 지역마다 일반 상대 7마리와 보스 1마리, 총 8마리를 처치해야 다음 지역으로 넘어간다. 4지역 보스를 처치하고 마지막 보상·선술집을 마치면 총 32처치로 탐험을 완료한다. 시작 시 열쇠는 한 번만 소모하며 지역 전환 때 추가 소모하지 않는다.

| 지역 | 이름 | 임시 보스 |
| --- | --- | --- |
| 1 | 엘윈 숲 | 아비아나 |
| 2 | 날개, 공업도시 | 검사 멜트라닉스 |
| 3 | 시간의 서고 | 희망의 끝 요그사론 |
| 4 | 빛이 잠든 곳 | 순수한 빛 미다 |

## 임시 상대 배치

배치 원본은 `content/지역-설계.json`이다. 현재 활성 상대 25종을 모두 배치했으며, 원래 비활성화된 역병 의사는 그대로 제외한다. 각 지역의 `enemies`는 일반 풀, `bosses`는 8번째 전투 전용 풀이다. 현재 보스는 지역별 1종이지만 여러 보스를 등록해 추첨할 수도 있다.

- 엘윈 숲: 대포 미니언, 작은 해츨링, 이상해풀, 뻐끔플라워, 아이번, 티모, 빛나래.
- 날개, 공업도시: 대포 미니언, 피카츄, 슈퍼 미니언, 함정의 방, 그림자보석공 하나르, 피오라, 패치워크, 흑기사.
- 시간의 서고: 안토니다스, 부끄부끄, 유미, 얼굴 없는 배후자, 그림자보석공 하나르, 빛나래, 함정의 방, 아우렐리온 솔.
- 빛이 잠든 곳: 리치 왕, 얼굴 없는 배후자, 부끄부끄, 유미, 흑기사, 아우렐리온 솔, 개십악질, 안토니다스.

같은 지역에서는 이미 처치한 상대를 다시 뽑지 않는다. 다른 지역에 같은 상대가 배치되어 있으면 다시 등장할 수 있다. 보스는 해당 지역의 일반 풀에 들어갈 수 없다. 미리보기에서 확정된 상대·무작위 덱·복제 결과는 저장하며, 거절·재접속·재시작으로 다시 추첨하지 않는다.

## 지역 전환과 저장

덱·보물·현재 체력·탐험 골드는 그대로 이어진다. 각 처치 후 카드 묶음, 휴식·제련, 이벤트 자리, 선술집의 기존 흐름도 유지한다. 별도 보물 획득·교체는 기존 누적 1·4·6처치 시점 그대로이며, 지역 전환 때문에 기존 보물 슬롯을 덮어쓰지 않는다.

새 탐험은 `regionVersion: 1`을 저장하고 `wins`는 누적 0~32를 뜻한다. 지역과 지역 내 전투 번호는 누적 처치 수로 계산한다. 기록에는 지역·상대·보스 여부도 저장한다. 이전 버전에서 시작한 탐험은 저장 형식을 보존해 기존 8전투 방식으로 끝낼 수 있다. 이 변경은 실제 유저 파일을 삭제하거나 초기화하지 않는다.

플레이어 최대 체력은 기존 60이며 자동 회복하지 않는다. 적 체력은 임시로 각 지역에서 기존 전투별 수치 15·20·25·35·40·50·60·70을 재사용한다. 적 배치와 수치는 최종 밸런스가 아니다.

## 사망·포기·완료 정산

계정 코인(C)과 탐험 골드는 별개다. 사망 시 남아 있던 탐험 골드는 코인에 더하지 않는다. 코인은 누적 처치 수와 RNG 보정만으로 계산하며, 동일 정산을 재접속·중복 입력으로 다시 지급하지 않는다. 포기와 최종 완료도 같은 처치 수 정산을 사용한다.

임시 코인 범위는 기존 0~8처치 보상표를 확장했다. 코인은 범위 안에서 50 단위로 무작위 지급한다. 8처치를 마칠 때마다 기존 8처치 범위인 1,000~1,500C를 누적하고, 남은 처치 수의 기존 범위를 더한다.

| 누적 처치 | 코인 범위 |
| --- | --- |
| 0 | 50C |
| 1 | 50~100C |
| 7 | 600~1,000C |
| 8 | 1,000~1,500C |
| 9 | 1,050~1,600C |
| 16 | 2,000~3,000C |
| 24 | 3,000~4,500C |
| 32 | 4,000~6,000C |

열쇠·강화석·정수는 기존 처치 수별 종료 보상표를 사용하며, 8처치 이후에는 기존 8처치 등급을 유지한다. 계정 재화는 기존 지급·상한 규칙을 따른다.
