# 전투 후 진행 · 중립 풀 개편

새 탐험은 탐험 골드 0으로 시작합니다. 계정 코인(C)는 선술집 통화와 구분합니다. 기존 탐험이 새 전투를 이기면 새 보상 흐름으로 전환합니다. 탐험 종료 시 남은 탐험 골드는 계정 코인(C)로 정산하며 기존 50~1500코인 및 열쇠·강화석·정수 무작위 종료 보상은 새 탐험에서 지급하지 않습니다.

## 진행 순서

1. 기존 보물 획득: 1승 하급 / 4승 상급 / 6승 보물 교체 유지.
2. 해당 직업 카드로만 구성된 3장 묶음 3개 중 하나를 선택하고, 선택한 카드 3장을 덱에 추가. 목록이 적은 직업도 3장 보상을 받도록 같은 카드가 중복될 수 있습니다.
3. 휴식(체력 10 회복) 또는 제련(강화 가능한 실제 카드 최대 3장을 무작위 제시하고 하나 강화). 대상이 없으면 제련을 건너뜁니다.
4. 이벤트 화면. 내용 미정으로 계속 버튼만 제공합니다. 임의의 이벤트 효과는 넣지 않습니다.
5. 선술집. 직업 카드 3장, 중립 카드 2장, 카드 제거를 제공합니다. 구매한 물품은 품절되며, 재접속해도 재추첨하지 않습니다. 나가기 전까지 여러 물품을 구매할 수 있습니다.
6. 나갈 때 보유 골드의 10%를 내림하여 이자로 지급하며 최대 5골드입니다. 같은 선술집에서 이자는 한 번만 받습니다.

8번째 승리도 위 단계를 마친 뒤 탐험을 정산합니다. 선택·구매·이자는 저장 및 입력 중복 방지의 적용 대상입니다.

## 수치

사용자가 수치를 지정한 범위 안에서 다음과 같이 정했습니다. 미지정 가격·확률은 여기 기록한 기본값을 사용합니다.

- 승리 골드: 4~6 균등 무작위 + `round((1 - 현재 체력 / 최대 체력) × 5)` 체력 보너스. 보너스 0~5.
- 카드 가격: `min(6, 3 + 기본 마나 비용)`으로 카드별 3~6골드 고정.
- 카드 제거: 첫 전투 후 3골드, 이후 전투마다 2골드 증가. 한 선술집에서 한 번 구매.
- 회복 물약: 체력 10 회복, 4골드. 등장 확률 `15% + 70% × 잃은 체력 비율`.
- 강화권: 강화 가능한 실제 카드 최대 3장 중 하나 강화, 5골드. 등장 확률 `15% + 70% × 현재 체력 비율`. 강화 대상이 있을 때만 등장.
- VIP 회원권: 카드·제거·물약·강화권 가격 1골드 할인, 최소 1골드.

## 카드 · 보물

- 중립 카드 풀은 새 목록의 108종입니다. 직업 전용 카드가 일반 생성이나 선술집의 공용 카드 칸에 섞이지 않습니다.
- 금단의 치유술은 거프 직업 카드로 이동했습니다. 자연의 해독·신의 권능: 재생은 중립 풀에서 제외하고 적 전용 카드로 유지합니다. 기존 저장 덱에 있는 카드는 제거하지 않습니다.
- 굽이치는 파도(기본·강화 비용 1), 치유의 손길, 풍요, 기적같은 성장, 접붙이기의 체력 회복은 같은 수치의 방어도 획득으로 바꿨습니다. 안도는 기본·강화 모두 방어도 5를 얻으며, 기존 조건과 드로우 수는 유지합니다.
- 같은 이름의 기존 상대 덱 카드 정의는 호환성을 위해 남겨 둡니다. 보상·중립 생성 풀에서는 새 목록만 사용합니다.
- 중립 보물 풀 62종, 직업 보물 13종, 시작 보물 6종. 예전 카드형 보물 ‘살라드라실’은 획득 풀에서 제외하고 새 자연 중립 카드 ‘살라드라실’로 제공합니다. 기존 저장본이 가진 옛 보물의 실행 정의는 보존합니다.
- ‘심판관의 반지’는 셀레스테와 아감마간에게 보물 보상으로 등장하지 않습니다.
- 손으로 생성되는 지속형 보물은 비용 0, 일회용 획득 카드로 표현합니다. 사용하면 그 전투에서 해당 지속 효과를 얻으며, 탐험 덱 추가를 명시한 효과만 영구 추가합니다.
- ‘해오름’은 메인 페이즈 1에서 추가 효과를 발동합니다.
- 새 원고에서 카드에 붙은 ‘취약’은 사용자 확인에 따라 ‘불안정’으로 수정했습니다. 플레어드라이브에는 불안정을 중복 표기하지 않습니다. 캐릭터 상태인 취약 키워드는 유지합니다.
- ‘강풍’은 다음에 직접 내는 첫 카드에 불안정을 적용합니다. 효과로 자동 사용하는 카드는 이 조건을 소비하지 않습니다.
- 원고의 ‘이건 내 거야!’ 강화형 제목 ‘동력 전환+’는 같은 카드의 강화형인 ‘이건 내 거야!+’로 정리했습니다. 노틸러스의 동력 전환과 구분됩니다.
- 저주 카드군(고드름·저주·혹한)은 [💔], 사용불가·일시적이며 상성·속성 변경 상호작용이 없습니다. 혹한은 레스트 이동 시 제외와 드로우라는 기존 고유 효과를 유지합니다.
- 위력은 기존 카드 위력 수치와 통합했습니다. 혈석·단검은 각각 최대 5개이며 UI에서 해당 캐릭터의 마나 아래에 표시합니다. 단검 소모는 각각 피해 4를 따로 처리합니다.
- 가속의 물약: 가득 찬 손패에서 뽑을 때마다 기존 손패의 첫 카드를 덱으로 돌려보내고 새 카드를 손에 넣습니다. 카드 생성에는 적용하지 않습니다.
- 시간 왜곡 물약: 통상 스탠바이 드로우를 총 4장으로 대체합니다. 전투 시작의 추가 4장 효과는 기존대로 유지합니다.

실행 원본: `src/journey.js`, `src/expansion.js`. 완성된 카드 설명은 게임 내 `+도감`에 반영되어 있습니다.

어스름: 메인 페이즈 2에서 추가 효과가 발동하는 키워드입니다. 아직 이 키워드를 사용하는 카드는 없습니다. 기존 계정 재화의 저장 필드와 잔액은 유지하며 화면·지급 안내에서 코인(C)으로 표시합니다. 탐험 골드와 선술집 가격은 골드로 유지합니다.
