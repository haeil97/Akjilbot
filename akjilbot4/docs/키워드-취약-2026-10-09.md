# 취약과 유령 걸음 변경

- **취약**: 이 카드는 같은 속성의 카드에도 **카운터**당합니다. 기본 상성에 의한 카운터도 유지됩니다. 상대 카드가 압도일 필요는 없습니다. 서로 취약이면 양쪽 모두 카운터당합니다.
- 부끄부끄의 유령 걸음은 피해를 무시하지 않습니다. 사용한 메인 페이즈에 받는 피해를 상대에게도 줍니다. 피해 감소 후의 피해량을 기준으로 하며 보호막에 흡수된 피해도 포함합니다. 반사 피해에는 카드 피해 증가를 더하지 않고 상대의 피해 방어와 보호막을 적용합니다.
- 사용한 페이즈의 제출 효과가 먼저 피해를 줘도 반사가 적용됩니다. 다른 페이즈에서는 반사하지 않습니다. 자기 피해와 막을 수 없는 피해에도 반응하며, 반사 연쇄는 기존 사망 이후 추가 반응 중단 규칙을 따릅니다.
- 부끄부끄 덱에서 신의 권능: 가속 2장과 예지 2장을 제거하여 총 36장입니다.
