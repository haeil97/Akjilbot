# 상대 전용 규칙 검토 — 2026-10-03

> 아래는 효과 구현 전의 설계 검토 기록이다. 현재 18종 능력과 전용 카드는 `src/bosses-v3.js`에 구현했으며, 현재 상태와 세부 해석은 [README](../README.md) 및 [입력할 설정](입력할-설정.md)을 우선한다.

이 문서는 `content/상대-능력.json`의 설계 메모다. 18종의 영웅 능력, 전용 카드 9종, 세례 대사 12개를 데이터로 정리했으며, 전투 엔진에 해당 동작을 구현했다는 뜻은 아니다. 기존 전투 엔진은 단순 피해·회복·드로우 등 일부 효과만 지원하므로 이 자료를 실행 가능한 카드 정의로 그대로 연결하면 안 된다.

## 그대로 보존한 조건

- 사용형 영웅 능력은 카드와 별개이며, 기본적으로 두 메인 페이즈를 합쳐 턴당 1회다. 비용은 제출 묶음 검증 시 지불하며, 상대의 현재 제출을 보기 전에 사용 여부를 결정한다.
- 패치워크는 사용 턴이 t이면 t+3부터 다시 사용할 수 있다. 세례는 전 턴에 사용했으면 이번 턴에 사용할 수 없다.
- 밴 해머+++의 +++는 카드 이름의 일부다. 이미 3회 강화된 카드가 아니며, 모든 전용 카드는 강화할 수 없다.
- 구원의 길은 **선천성·일회용**이다. 최초 성공 사용 시 50턴 카운트를 시작한다. 이미 카운트가 진행 중이면 매 엔드 페이즈에 기본 1턴을 줄이고 양쪽이 신성 카드를 **직접 사용한 장수만큼** 추가 감소한다. 직접 사용은 카운터당해도 집계하고 자동 사용은 제외한다. 어떤 경로로 다시 사용하더라도 카운트 생성·초기화는 하지 않는다. 정상 수동 재사용이면 기존 카운트만 1 감소한다. 최초 발동은 카운트를 50으로 설치하는 것으로 정리했다.
- 불길한 존재감은 아우렐리온 솔과 리치 왕이 공유하는 전용 카드 1종이다.
- 얼굴 없는 배후자는 플레이어 탐험 덱의 강화·중복 카드와 카드형/지속 효과형 보물을 복제한다. 유물과 플레이어 영웅 능력을 복제한다고 명시되지는 않았다. 카드 객체 자체를 공유하지 않고 별도 인스턴스로 만들어야 한다.
- 모든 전투의 손패 상한은 후속 답변으로 **8장**이 되었다. 시작 손패는 기존대로 4장이며 개십악질 전투에서는 비활성화 3장을 추가해 총 7장을 정상 보유한다. 이 지급이 플레이어 탐험 덱을 영구히 바꾸는 것으로 해석하지 않는다.
- 우주의 균형은 후속 답변으로 **1마나 사용형, 턴당 1회**가 되었다. 사용할 때마다 이번 전투에서 내 카드 피해량·회복량 +1이 누적된다.
- 카드 장수 언급이 없으면 1장을 뜻한다. 수풀 가꾸기는 서로 손패의 비자연 카드 **1장만** 덱에 섞고 자연 카드 **1장씩** 뽑는다. 대상 선정은 게임의 기본 카드 선택 처리 규칙을 따른다.
- 세례 대사는 사용 횟수에 따라 원문 순서로 출력한다. 12회째 사용 후 백야로 변신하고 현재/최대 체력은 100/100이 된다.
- 백야 전투에서 15초 동안 제출하지 않으면 그 메인 페이즈에 플레이어가 카드를 내지 않은 것으로 취급하고 다음 페이즈로 진행한다. 영웅 능력도 미제출한 빈 행동으로 정리했다. 봇이 꺼진 동안의 시간 계산은 아직 미정이다.
- 백야 변신 시 손패·뽑을 카드 더미·레스트의 일반 카드를 강화한다. 전용 카드 예고는 강화 불가라는 공통 규칙을 우선한다. 제외 영역은 대상에 적혀 있지 않다.
- 수정구는 매 스탠바이에 **손패에 있는 것만** 변신한다. 변신한 카드의 이름·속성·비용·효과를 사용하며, 사용 후 레스트로 갈 때 수정구로 복원한다. 변신 정보와 원본 카드의 정체를 함께 보존해야 한다.
- 독버섯은 덱에서 어떤 효과로든 뽑힐 때만 자동 시전한다. 자동 시전은 마나를 쓰지 않으며 해결 영역에 둔 채 자기 피해와 후속 드로우를 모두 처리한 뒤 레스트로 이동한다. 해결 중인 카드는 리필하지 않는다. 다른 경로로 손패에 들어오면 자동 시전하지 않으며, 1마나를 내고 직접 사용할 수 있다.
- 조건부 드로우도 기존 덱·리필 규칙을 따른다. 뽑을 카드 더미에 카드가 남아 있지만 조건에 맞는 카드가 없으면 뽑지 않는다. 더미 전체가 비었을 때만 레스트를 리필한 뒤 조건을 적용한다.

## 후속 답변으로 해결한 충돌

1. **개십악질 시작 손패:** 전체 손패 상한이 8장으로 변경되어 기본 4장+비활성화 3장을 모두 보유할 수 있다. 별도 예외 슬롯이나 카드 제외가 필요 없다.
2. **백야의 15초 제한:** 해당 메인 페이즈를 자동 패스한 뒤 다음 페이즈로 진행한다. 봇 종료 시간의 취급만 남았다.
3. **우주의 균형:** 1마나 사용형이며 턴당 한 번, 효과가 사용마다 누적된다.
4. **수풀 가꾸기:** 손패의 비자연 카드 1장을 돌려보내고 자연 카드 1장을 뽑는다. 손패 전체 교체가 아니다.
5. **수정구:** 손패만 변신 대상이다.
6. **구원의 길:** 일회용 추가, 최초 성공 사용 시 카운트 시작, 정상 수동 신성 사용만 감소, 재사용 시 별도 카운트 생성·초기화 없음으로 확정했다.
7. **조건부 드로우:** 후보가 없다는 이유만으로 레스트를 섞지 않는다. 뽑을 더미 전체가 빈 경우에만 리필한다는 기존 규칙을 적용한다.
8. **독버섯 연쇄:** 후속 드로우까지 모두 해결한 후 레스트로 이동한다는 기존 순서를 적용한다. 해결 중인 독버섯은 리필되지 않으므로 독버섯만 남아도 연쇄는 유한하게 끝난다.

## 구현 전에 좁혀야 하는 표현

- **백야의 종료 시간:** 봇이 꺼져 있던 시간을 15초에 포함할지, 재개 때 응답 시간을 보장할지.
- **특수 승리:** 경고 3회/구원의 길 승리와 체력 0이 같은 페이즈에 발생했을 때의 판정 우선순위. 일반 동시 사망은 이미 탐험 실패로 확정되어 있다.
- **처형:** 사용 여부는 미리 결정하되, 실제로 카운터할 카드 1장을 무작위로 고를지 다른 기준으로 고를지.

광기는 양쪽 레스트에서 각각 무작위 1장씩 제외하는 것으로 정리했다. 세례의 연속 사용 금지는 문맥상 변신 전 역병 의사에 적용했다. 이 두 항목은 추가 규칙을 만든 것이 아니라 문장 해석을 명시한 것이다.

## 구현 시 필요한 안전장치

- 영웅 능력의 사용 여부, 남은 쿨다운, 우주의 균형 누적량, 경고 수, 세례 횟수/대사 번호, 백야 변신, 구원의 길 카운트는 전투 상태에 저장해야 한다. UI 다시 출력이나 재시작이 이 수치를 초기화하면 안 된다.
- 역병 의사의 무작위 덱, 수정구의 매번 변신 결과, 무작위 탈취/제외 대상, 발견 선택지는 해당 단계에서 결정해 함께 저장해야 한다. 재접속 때 다시 뽑으면 안 된다.
- 시간 제한을 실제 시간으로 구현한다면 페이즈의 시작 시각/마감 시각/처리 완료 여부를 영속 저장해야 한다. 시간 초과 판정과 카드 제출은 같은 저장 트랜잭션 안에서 경쟁을 막아야 한다. 봇이 꺼진 동안 JavaScript 타이머는 작동하지 않으므로 종료 시간 처리 정책을 먼저 정해야 한다.
- 독버섯은 해결 중인 카드 영역에 두고 자기 피해→후속 드로우 전체 해결→레스트 이동 순서를 지킨다. 이를 지키면 독버섯만 남은 경우에도 아직 해결 중인 독버섯을 다시 뽑지 않으므로 연쇄가 유한하게 끝나며, 기존의 페이즈 양쪽 효과 후 사망 판정을 유지할 수 있다. 해결 중인 카드와 중첩 드로우 해결 스택을 함께 저장해 재시작 후 같은 순서로 이어가야 한다.
- 밴 해머+++의 제외→레스트 교체 효과는 사용 후 이동뿐 아니라 상대 효과에 의한 제외에도 적용되는 문장이다. 카드 소유자, 실제 이동 영역, 경고로 인한 상대 추방을 서로 다른 상태로 관리해야 한다.
