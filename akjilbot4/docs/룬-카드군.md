# 룬 카드군

- 카드에 `rune: true`를 지정합니다. 속성은 기존 속성을 유지하며 표시에서만 오른쪽에 💎를 붙입니다. 예: `[🔥💎] 카드명`.
- 룬이 실제로 발동할 때 활성 영역 `fighter.runes`로 이동합니다. 사용 후 레스트 정산에서 제외되어 턴과 페이즈가 바뀌어도 유지됩니다.
- 캐릭터마다 활성 룬은 최대 1개입니다. 새 룬이 발동하면 기존 룬의 실제 카드를 레스트로 보내고, 기존 룬의 지속 효과를 종료합니다. 양쪽의 룬은 서로 영향을 주지 않습니다.
- 새 룬이 카운터당하면 그 카드만 기존 카운터 규칙에 따라 레스트로 이동하며, 기존 활성 룬을 유지합니다.
- 자동 사용으로 발동한 룬도 같은 교체 규칙을 적용합니다.
- 활성 룬은 전투 상태에 `• [🔥💎] 카드명` 한 줄로 표시합니다. 효과 설명과 남은 턴수는 붙이지 않습니다. 손패와 도감에는 일반 카드처럼 비용과 설명을 표시합니다.
- 활성 룬은 손패가 아니므로 일시적·휘발성의 손패 정리 대상이 아닙니다.
- 활성 카드와 효과 정의는 저장·재접속 시 보존됩니다. 룬이 활성 영역을 떠나면 지속 효과가 종료되며, 그 룬을 원천으로 예약한 룬 효과도 중단됩니다.
- 아직 실제 룬 카드 목록은 지정되지 않았으므로 보상 풀에 임의의 룬 카드를 추가하지 않습니다.

## 카드 정의

`runeEffects`는 활성 중에만 적용되는 지속 수치입니다. 현재 지원 항목은 `damageBonus`, `healBonus`, `damageReduction`, `cardCost`, `powerCost`이며 `amount`로 수치를 지정합니다. `cardCost`, `powerCost`의 음수 수치는 비용 감소입니다.

`runeTriggers`는 활성 중 특정 이벤트에 추가 효과를 발동합니다. `event`와 `effects`를 지정합니다. 이벤트에 캐릭터가 지정되면 기본적으로 자신의 이벤트에만 반응하며, `side: "opponent"` 또는 `"both"`로 범위를 바꿀 수 있습니다. `includeSelf: true`가 없으면 자기 룬 카드 자체의 이벤트는 제외합니다.

일반 `effects`나 기존 카드 실행 규칙은 발동 시 한 번만 처리합니다. 룬의 지속 수치는 `runeEffects`, 반복 반응은 `runeTriggers`로 정의하여 교체 시 더 이상 적용되지 않게 합니다. 예약 효과는 원천 룬의 활성 여부를 확인합니다.

```js
{
  name: '예시 룬', // 구조 예시이며 실제 획득 카드에 등록하지 않음
  element: 'FIRE', cost: 1, rune: true, effects: [],
  runeEffects: [{type: 'damageBonus', amount: 2}],
  runeTriggers: [{event: 'standby', effects: [{type: 'damage', amount: 3}]}]
}
```
