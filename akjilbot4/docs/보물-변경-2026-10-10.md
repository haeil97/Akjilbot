# 보물 변경

- 재활용 쓰레기통: 카운터당한 카드마다 방어도 5.
- 남극 시계: 직접 낸 카드의 지불 비용이 0이면 상대에게 피해 4. 카운터당해도 발동하며 자동 시전과 영웅 능력은 제외.
- 끝없는 파도: 엔드에 손패 2장 이하이면 다음 스탠바이에 추가 드로우 1.
- 펠고지의 지갑: 손패 한도 +3, 기본 한도 8에서 11.
- 심판관의 반지: 상급 지속형. 패자의 축음기: 하급 지속형.
- 제피르스의 램프: 선천성 삭제.
- 도둑의 갈고리: 비용 0. 상대 손에서 발견하여 레스트로 보낸 뒤, 내 레스트에서 발견하여 손으로 가져옴. 한쪽 영역이 비어도 다른 효과는 처리.
- 톨린의 술잔·가득 찬 가방·네더 차원문: 비용 0.
- 메아리 조각: 복사하여 가져온 카드의 비용 1 감소, 최소 0. 기존 손패 이탈 시 할인 해제 규칙을 적용.
- 인피니티 스톤: 비용 4.
- 소매치기 장갑: 상대 손에서 2장 훔침.
- 네더 차원문: 가져온 카드는 이번 턴이 끝나도 손에 있는 동안 비용 0 유지. 기존 손패 이탈 시 할인 해제 규칙을 적용.
- 파괴의 구슬: 일회용 추가.
