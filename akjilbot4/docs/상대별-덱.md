# 악질봇 4.0.0 상대별 덱 설계안

사용자가 정한 상대·영웅 능력·전용 카드를 바탕으로 만든 **검토 가능한 덱 초안**입니다. 카드명·장수·중복 제한은 검증했으며, 모든 효과와 AI가 완성되어 실제 난도까지 검증된 상태는 아닙니다.

일반 카드는 기본적으로 강화되지 않은 원본으로 시작합니다. 아비아나는 지정된 예외로 성지순례+ 1장을 포함합니다. 같은 카드명은 기본 최대 2장이고 지정된 예외만 더 넣습니다. 전용 카드는 수정구를 제외하면 강화할 수 없습니다. 수정구+는 매 스탠바이 페이즈마다 강화된 일반 카드로 변신합니다. 시작 손패 4장, 최신 손패 상한 8장, 전투 시작 최대 마나 1을 기준으로 구성했습니다. 마나 획득 카드는 메인 1에서 사용한 뒤 메인 2의 비용으로 활용합니다. 같은 제출 묶음 안에서 얻을 마나를 미리 쓸 수 없습니다.

AI는 공개된 카드 사용 제한·금지 속성·속성 변경을 현재 턴에 맞춰 예측에 반영합니다. 두꺼비집으로 전기 취급 중이면 자연 카드를, 북부 항해 등으로 냉기만 사용 가능하면 전기 카드를 더 선호합니다. 속성 변경 후의 속성에 사용 제한을 적용하며, 낼 수 있는 속성이 전혀 없으면 카운터 목적의 우선도를 주지 않습니다. 제한의 시작·만료 시점을 확인하고 플레이어의 숨겨진 손패·덱 내용을 사용하지 않습니다.

### 대포 미니언 — 8장

**영웅 능력: [🛟] 공성 | 지속형**

매 턴의 엔드 페이즈시에 상대에게 피해를 1 줍니다.

자연·화염·냉기를 섞어 공격과 회복을 번갈아 쓰며 공성 피해를 누적하는 첫 상대.

| 카드 | 비용 | 장수 |
|---|---:|---:|
| 🍃 산사태 | 1 | 2 |
| 🍃 재생 | 1 | 1 |
| 🍃 살아 움직이는 숲 | 1 | 1 |
| 🔥 화염구 | 1 | 2 |
| ❄️ 완전 빙결 | 1 | 2 |

- 자연 4장, 화염 2장, 냉기 2장으로 구성해 단일 속성 대응만으로 공략되지 않게 했습니다. 신성은 없습니다.
- 모두 비용 1입니다. 화염구와 완전 빙결로 카드를 보충하고, 재생으로 버티며 공성 피해를 누적합니다. 완전 빙결로 뽑은 카드는 다음 턴부터 사용할 수 있습니다.
- 산사태의 추가 드로우 조건을 충족하는 고비용 카드는 없습니다. 이 덱에서는 기본 피해 4를 주는 단순 공격 카드로 사용합니다.
