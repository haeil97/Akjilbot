# 누적 탐험 통계

`+통계` 또는 `+ㅌㄱ`로 전체 누적 속성·일반 카드·보물의 선택률/평균 승수와 봇별 격파율을 조회합니다. 3.1.0처럼 접기 문자 1,000개 뒤에 속성별·카드별·봇별 내용을 출력하고 보물별 구간을 추가합니다.

- 선택률은 선택/제시 횟수입니다. 일반 카드 추가 보상과 보물 선택·교체 보상에서 선택을 확정할 때 집계합니다. 같은 선택지의 중복 항목은 한 번 셉니다. 고정 시작 덱, 강화·제거 선택, 전투 중 발견, 무작위 보물 획득은 선택률에서 제외합니다.
- 평균 승수는 해당 일반 카드·속성·보물을 탐험 종료 시 보유 중인 탐험들의 최종 승수 합/종료 탐험 수입니다. 0~8승이며 탐험당 종류별 1회, 카드의 기본·강화판과 여러 복사본은 합산합니다. 시작 카드, 효과로 탐험 덱에 영구 추가된 카드, 무작위로 얻은 보물도 평균 승수에 포함합니다. 중간에 제거·교체되어 종료 시 없는 항목은 평균 승수에서 제외합니다. 선택률 기록은 유지합니다. 토큰·전용 카드·카드형 보물은 일반 카드 구간에서 제외하고 보물은 별도 집계합니다.
- 진행 중인 탐험의 선택률은 즉시 반영하지만 평균 승수는 탐험 종료 후에 반영합니다.
- 봇별 격파율은 플레이어 승리/(승리+패배)입니다. 전투 중 포기는 패배로 집계하고, 상대 미리보기·보상 단계 포기는 전투 결과를 추가하지 않습니다. 귀환석 탈출·재시도는 결과를 기록하지 않습니다.
- 집계는 업데이트 이후부터 시작하며 과거 결과는 소급하지 않습니다. 기존 저장소에는 첫 집계 시 통계 영역을 추가합니다.
- `state.stats`에 전역 누적으로 저장합니다. 명령어 처리 트랜잭션 안에서 선택·결과를 저장하므로 동일 입력 재전송 및 저장소 재시작으로 중복 집계되지 않습니다. 조회는 계정 생성, RNG 소비, 세션 갱신, 저장소 쓰기를 하지 않습니다.
