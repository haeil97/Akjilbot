# 2026-10-02 추가 확정 규칙

이 문서는 영웅·두 메인 페이즈·신규 카드 도입 이후의 사용자 결정을 기록한다. 이전 설계와 충돌하면 이 문서 및 이후 답변을 우선한다. 2026-10-03에는 거프와 기본 덱 8종, 양성 및 두 메인 페이즈를 JS에 연결했다. **일반 카드 100종 전체의 구현 완료를 뜻하지는 않는다.**

## 콘텐츠와 영웅

- 일반 카드 100종과 토큰 설명을 받았다. `../content/일반카드-원고.txt`는 개발용 작업 원고이며 실행 시 외부 파일로 읽지 않는다. 원문 참조 자료는 단일 JS의 `A4.content`에 포함했고, 실행 효과는 구현된 항목만 `A4.catalog.cards`에 있다.
- 성지순례·성지순례+의 `이 효과는 중첩될 수 있습니다.` 문장 두 곳을 작업 원고에서 삭제했다. 첨부 원본은 보존한다.
- 영웅을 선택하면 해당 영웅의 능력과 기본 덱을 얻는다. 첫 영웅 거프의 덱은 8장이며 시작 손패는 4장이다. 나중에 영웅 목록을 확장한다.
- 사용형 능력은 일반적으로 턴당 1회, 마나 비용이 있을 수 있고 사용 후 없어지지 않는다. 다음 턴에 재활성화한다. 지속형 능력도 있다.
- 거프의 사용형 능력 [🌊] 양성은 1마나로 체력 3 회복, 턴당 1회다. 두 메인 페이즈 중 원하는 곳에서 카드와 함께 제출한다. 카드가 아니므로 카운터 대상이 아니며 카드 사용 금지 중에도 사용하고 카드 사용 횟수에도 포함하지 않는다.
- 거프 덱: 수중 동물 변신(0), 급속 성장(2), 치유의 손길(2), 급속 빙결(1), 초고속(1), 선조의 지혜(0), 천둥(1), 파지직(1).
- 단계별 플레이어 기본 최대 체력은 `[15,20,25,30,35,40,45,50]`. 전투마다 완전 회복하고 일반 전투 상태를 초기화한다.

## 속성과 페이즈

- 냉기 → 화염 → 자연 → 전기 → 냉기의 상성. 기존 물리 자리를 자연으로 대체한다. 신성은 기본 상성 없음, 🌊는 토큰용 무속성이다.
- 스탠바이 → 메인 1 → 메인 2 → 엔드. 0턴은 시작 손패 4장만, 기본 드로우는 1턴부터다.
- 스탠바이마다 마나 충전·기본 1장 드로우·해당 시점 효과를 처리한다. 기본 최대 마나는 0턴 1, 5턴 2, 10턴 3, 15턴 4, 20턴 이후 5.
- 메인 1에서 양쪽 일괄 제출·상성·효과·레스트 이동까지 처리한 뒤 메인 2를 진행한다. 두 페이즈는 마나를 공유하며 메인 1에 얻은 카드는 별도 제한이 없으면 메인 2에 쓸 수 있다.
- 각 페이즈에서 양쪽 효과를 모두 처리한 뒤 사망 판정. 동시 사망은 탐험 실패.
- 상대는 메인 2 행동을 메인 1 결과로 결정하지만 플레이어의 메인 2 제출은 보지 않는다. 초고속 등 명시적 예외는 적용한다.

## 마나

- 일시적 마나는 현재 최대치를 넘어 보유 가능하나 현재 마나 5를 초과하지 않는다. 회복은 최대 마나까지만 한다.
- 급속 성장(답변의 ‘금속 성장’)은 최대 마나만 1 증가시킨다.
- 초과 인출은 다음 턴에 걸릴 과부하도 취소한다.
- 과부하 카드가 카운터당하면 과부하도 무효다.
- 같은 묶음의 마나 획득 효과를 예상해서 비용을 지불할 수 없다. 제출 시 가진 마나로 비용을 충족해야 한다.
- 금단의 불꽃과 다른 카드의 비용 지불 순서는 아직 명시되지 않았다.

## 손패와 키워드

- **2026-10-03 최신 답변 기준 상한은 8장이다.** 중간 결정인 6장을 대체한다. 시작 손패는 여전히 4장이며, 개십악질 전투는 비활성화 3장을 추가해 7장으로 시작한다.
- 드로우·생성·복사·탈취·회수 등 모든 경로에서 초과 카드를 제외한다. 기존의 ‘만패면 뽑지 않고 덱에 남김’은 폐기한다.
- 치명타는 여러 장을 카운터해도 해당 카드당 한 번만 발동한다.
- 제한은 원본·강화본을 같은 이름 묶음으로 취급하고 메인 1·2를 합쳐 턴당 한 번이다.
- 버린 카드는 레스트로 간다.
- 일시적 카드는 엔드 페이즈에 레스트로 간다. 엔드 페이즈 중 새로 얻은 일시적 카드는 다음 턴 엔드까지 유지한다.
- 마법공학 자동 발동은 마나를 소모하지 않는다.
- 불안정은 카운터당하면 제외, 일회용은 사용 후 레스트 대신 제외, 선천성은 시작 손패 우선이다. 선천성이 시작 장수보다 많으면 그중 시작 장수만 들어온다.

## 발견과 자동 사용

- 생성·발견 기본 대상은 비강화 일반 카드. 별도 문구가 없으면 보물·토큰·강화본은 제외한다.
- 발견 카드는 자기 자신을 찾지 못하지만 다른 발견 카드는 찾을 수 있다. 3.1.0의 다른 발견 카드 제외 필터를 그대로 쓰지 않는다.
- 운명·필연 등 효과로 카드를 사용하면 추가 마나와 사용 횟수 판정이 없다. 자동 사용 카드의 상성 판정 여부는 미정이다.

## 개별 카드와 표현

- `내 덱`은 현재 뽑을 카드 더미. `이번 턴에 상대가 사용한 카드`는 메인 1·2 합산 기록. `상대가 낸 카드`는 현재 메인 페이즈 제출.
- `다음 턴에`는 다음 턴만. `다음 턴의 엔드 페이즈시까지`는 사용 직후부터 다음 턴 끝까지.
- `이번 게임`은 기본적으로 해당 전투이며, 탐험 덱에 추가·제거한다고 명시한 효과는 탐험 전체에 적용한다.
- 점화는 계속 누적하며 점화+와 공유한다.
- 태양 작렬은 누적 피해 기준이다. 한 번 발동 후 종료인지 기간 중 반복인지 아직 미정이다.
- 충전으로 강화된 카드는 해당 다음 턴 끝에 이전 상태로 돌아온다.
- 고철 더미에서는 카드형 보물만 발견한다. 기존 보물 2개와 별도로 쌓이고 이미 가진 보물도 후보가 된다. 이 경로로 얻은 보물도 교체 대상이다. 기존 중복 금지의 명시적 예외다. 교체 대상이 여러 개일 때 선택 방법은 미정이다.
- 심해 저주: 저주 토큰, 무속성, 1마나, 일회용, 손패에 있으면 엔드마다 보유자에게 피해 3.
- 심해 저주+: 저주+ 토큰, 무속성, 2마나, 일회용, 손패에 있으면 엔드마다 보유자에게 피해 5.
- 방어도로 막힌 피해도 받은 피해에 포함한다.
- 같은 지속 효과는 중첩한다. 성지순례의 별도 중첩 설명은 삭제한다.
- 장수 언급이 없으면 1장이다. 아이번은 양쪽 손에서 자연이 아닌 카드 1장씩만 덱에 넣고 각자 자연 카드 1장을 뽑는다.

## 상대 설계 추가 결정

- 상대 기본 체력은 1~8전투 순서로 10/15/20/30/40/50/60/70이다. [상대별 덱](상대별-덱.md)에 18종과 공유 후보 풀을 정리했다.
- 속성 비율 후속 수정: 대포 미니언은 최소 2속성(설계는 자연 4·화염 2·냉기 2장), 아이번은 자연 10/20장, 리치 왕은 냉기 20/40장, 미다는 신성 10/30장으로 맞췄다. 개십악질은 화염·냉기·자연·전기·신성 각 6장이다. 덩굴뿌리 4장·아이번 전기 금지·밴 해머+++ 2장·구원의 길 1장 조건은 유지한다.
- 모든 전용 카드는 강화 불가. 밴 해머+++의 +++는 이름 일부다. 백야 변신 때도 예고는 강화하지 않는다.
- 솔의 우주의 균형은 1마나 사용형이며 턴당 1회, 사용마다 이번 전투의 카드 피해량·회복량 +1이 누적된다. 수정구는 손패에 있을 때만 스탠바이 변신한다.
- 백야는 각 메인 페이즈 15초 제한. 제출이 없으면 플레이어가 카드와 능력을 사용하지 않은 것으로 처리하고 상대 행동을 해결한 뒤 다음 페이즈로 진행한다. 봇이 꺼져 있던 시간의 처리는 아직 미정이다.
- 구원의 길은 선천성·일회용. 최초 성공 사용 시 카운트를 시작하며, 이미 카운트가 있으면 재사용으로 추가 카운트를 만들거나 초기화하지 않는다. 매 엔드 페이즈에 기본 1턴을 줄이고, 양쪽이 직접 낸 신성 카드마다 추가로 1턴씩 줄인다. 카운터당한 직접 사용도 포함한다. 자동 사용 신성 카드는 감소시키지 않는다. 최초 카운트는 50으로 설치하는 해석을 명세에 기록했다.
