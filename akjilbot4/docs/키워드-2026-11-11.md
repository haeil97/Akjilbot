# 2026-11-11 전투 규칙과 키워드

양쪽 모두 현재·최대 마나 2로 시작한다. 5·10·15턴에 최대 마나가 1씩 증가하며 5가 상한이다. 탈진은 표시 20턴의 스탠바이부터 1, 2, 3… 피해이며 보호막을 무시한다.

기존 카드의 불안정 표기는 삭제한다. 기존 취약 표기는 불안정으로 바꾼다. 카운터 시 제외 규칙은 폐지한다. 일회용은 카운터되면 레스트, 정상 사용하면 제외다.

신규 카드는 아직 추가하지 않는다. 공통 처리의 규격은 다음과 같다.

- 효과 `disarm`, `vulnerable`, `weakened`: 캐릭터 상태. `turns:2`라면 현재 턴부터 두 턴 뒤 END까지 유지 후 해제한다. `target:'self'`가 아니면 상대에게 적용한다.
- `degrade`: 지정 대상의 `zones`(기본 손패)에 있는 강화 카드를 기본으로 되돌린다. `uid`로 단일 카드를 지정할 수 있다.
- `dredgeKeyword`: 덱 밑 3장 중 1장을 위로 이동한다. 자동 드로우하지 않는다. 기존 카드의 인양 후 드로우는 해당 카드 고유 효과다.
- `shock`, `amount:n`: 상대 최대 마나 이하 비용의 사용 가능한 손패를 중복 없이 n장까지 봉쇄한다. 현재 마나 부족은 선택 대상에서 제외하는 이유가 아니다. 다음 턴 END가 끝나면 풀린다.
- `discardBottom`, `amount:X`: 자기 덱 밑에서 X장까지 레스트로 보낸다. 폐기 중 덱이 비어도 침몰을 달성한다.
- `execution`, `amount:n`: 대상에게 처형 중첩 부여. 스탠바이에 HP < 중첩이면 방어도와 관계없이 사망, 아니면 중첩 1 감소. 같은 스탠바이에 중복 처리하지 않는다.
- `sinking`, `awakening`의 `effects`: 각각 덱이 빈 적이 있음/최대 마나 5 달성 이력이 있으면 추가 효과 실행. 이번 전투 동안 기억한다.
- 카드 `liberation` 조건: `sinking`, `awakening`, `turn`, `hpBelow`, `played`, `orbit`와 `all`/`any` 조합을 지원한다. 새 카드 추가 시 구체적 조건을 지정한다.
- 카드 `orbit:{count:N,effects:[...]}`: 손에 머무는 동안 다른 카드 사용을 N회 집계해 추가 효과를 한 번 실행한다. 손에서 나갔다 돌아오면 집계를 초기화한다. 자동 사용도 다른 카드 사용이면 포함한다.
- 카드 `unstable`: 같은 속성에도 카운터된다. `volatile`: 손에 남아 있으면 END에 제외된다. 새 카드는 아직 이 키워드를 사용하지 않는다.
- 취약은 받은 피해 ×1.5, 약화는 가한 피해 ×0.75, 각각 소수점 버림. 약화→취약 순서 후 방어·피해 제한을 적용한다. 막거나 줄일 수 없는 피해에는 이 배율을 적용하지 않는다.
